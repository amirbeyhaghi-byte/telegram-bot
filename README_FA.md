# نسخه PHP ربات مزاج‌شناسی بیهقی — انتقال قابلیت‌ها از نسخه پایتون

این پروژه همان ربات است، به PHP. تا زمان انتقال نهایی روی **سیستم خودتان** تست می‌شود
(با روش polling، بدون هاست و بدون HTTPS)، و همان کد بعداً روی هاست با **وب‌هوک** اجرا می‌شود.

> برای تست از یک **ربات تستی جدا** استفاده کنید (BotFather ← `/newbot`)، نه ربات اصلی.
> ربات اصلی تا پایان انتقال روی نسخه پایتون روشن می‌ماند.

## ۱. نصب ابزار روی ویندوز (یک‌بار)
1. **XAMPP** را نصب کنید (PHP 8.2 + MariaDB + phpMyAdmin در یک بسته). فقط «Apache» و «MySQL» را روشن کنید (Apache لازم نیست، MySQL لازم است).
2. مسیر PHP را به PATH ویندوز اضافه کنید: `C:\xampp\php` (جستجوی «Environment Variables» ← Path ← New). PowerShell را دوباره باز کنید و بزنید:
   ```
   php -v
   php -m
   ```
   نسخه باید 8.1 به بالا باشد و در `php -m` این موارد دیده شود: `curl`، `mbstring`، `pdo_mysql`، `openssl`.
   (اگر نبود، در `C:\xampp\php\php.ini` خط‌های `extension=curl` و ... را با حذف `;` اول خط فعال کنید.)
3. در VS Code افزونه **PHP Intelephense** را نصب کنید (اختیاری، برای تکمیل کد).

## ۲. دیتابیس
در مرورگر `http://localhost/phpmyadmin` را باز کنید ← New ← نام `beyhaghi_php` ← Collation: `utf8mb4_unicode_ci` ← Create.

## ۳. تنظیمات
فایل `.env.example` را کپی کنید به `.env` و پر کنید:
- `BOT_TOKEN` ← توکن ربات تستی
- `ADMIN_PHONE` و `ADMIN_TELEGRAM_ID` ← مثل نسخه پایتون
- اگر فیلترشکن شما فقط روی خودش پورت پروکسی محلی باز می‌کند، `TELEGRAM_PROXY` را پر کنید (مثلاً `socks5://127.0.0.1:10808`). اگر کل سیستم با فیلترشکن کار می‌کند، خالی بگذارید.
- اگر خطای «SSL certificate problem» گرفتید: `TELEGRAM_CA_BUNDLE=C:\xampp\apache\bin\curl-ca-bundle.crt`

## ۴. ساخت جدول‌ها و آزمون
در پوشه پروژه (ترمینال VS Code):
```
php bin/migrate.php
php bin/selftest.php
php bin/selftest.php --db
```
- `migrate` جدول‌ها را می‌سازد.
- `selftest` توابع را بدون تلگرام و بدون دیتابیس می‌سنجد.
- `selftest --db` کل جریان ثبت‌نام ← خروج ← ورود ← غیرفعال‌سازی را روی دیتابیس شبیه‌سازی می‌کند (فقط شماره تستی 09990000001 را می‌سازد و پاک می‌کند).

همه موارد باید ✅ باشند. هر ❌ را همراه خروجی برایم بفرستید.

## ۵. اجرای ربات
```
php bin/poll.php
```
در تلگرام به ربات تستی `/start` بفرستید. توقف: `Ctrl+C`.
(فیلترشکن را روشن کنید یا `TELEGRAM_PROXY` را پر کنید.)

## قابلیت‌های انتقال‌داده‌شده به PHP
- `/start`، درباره سامانه، ثبت‌نام، ورود، خروج و بررسی حساب غیرفعال
- ثبت خودکار اشتراک رایگان ۳۰ روزه پس از ثبت‌نام
- آزمون مزاج‌شناسی با ۳۰ پرسش واقعی نسخه پایتون، گزینه‌های تصادفی، درصدها و نتیجه مزاج غالب
- فهرست و جستجوی ۲۳۶ خوراکی از داده‌های `seed_foods.py` نسخه پایتون، همراه با دسته، گونه و طبع
- نمایش حساب کاربری و وضعیت اشتراک
- اشتراک‌های ماهانه، ۶ ماهه و سالانه با قیمت‌های فعلی تعریف‌شده در نسخه پایتون
- کدهای هدیه، ساخت کد توسط مدیر، فهرست و غیرفعال‌سازی کدها
- پرداخت کارت‌به‌کارت با ثبت فاکتور، دریافت تصویر فیش، ارسال برای مدیر و تأیید/رد دستی
- جستجو و فعال/غیرفعال‌سازی حساب کاربران از پنل مدیریت
- نگهداری وضعیت گفتگو در MySQL؛ بدون نیاز به Redis

**توجه:** پرداخت‌ها در این نسخه همچنان کارت‌به‌کارت و با تأیید دستی مدیر هستند؛ درگاه بانکی آنلاین به‌صورت خودکار متصل نشده است. قیمت‌ها و اطلاعات کارت مقصد باید قبل از استفاده واقعی بازبینی شوند.

## مهاجرت دیتابیس و واردسازی خوراکی‌ها
پس از قرار دادن فایل‌های نسخه جدید، در ترمینال VS Code و پوشه اصلی پروژه اجرا کنید:
```
php bin/migrate.php
php bin/import_reference_data.php
php bin/selftest.php
php bin/selftest.php --db
```
دستور واردسازی ۲۳۶ خوراکی را فقط وقتی جدول `food_items` خالی باشد وارد می‌کند و از داده تکراری جلوگیری می‌کند.

در `.env` این سه مقدار را فقط اگر می‌خواهید پرداخت کارت‌به‌کارت را آزمایش کنید تنظیم کنید:
`PAYMENT_CARD_NUMBER`، `PAYMENT_CARD_BANK` و `PAYMENT_CARD_OWNER`.
برای مدیر، `ADMIN_PHONE` و `ADMIN_TELEGRAM_ID` باید با مقادیر واقعی نسخه خودتان تنظیم باشند.

## ساختار
```
bin/            migrate.php  poll.php  selftest.php  set_webhook.php  delete_webhook.php
public/         webhook.php          (نقطه ورود وب‌هوک؛ فقط برای هاست)
src/            کدهای برنامه (Bot, Services, Telegram, State, ...)
migrations/     فایل‌های SQL ساخت جدول (MySQL)
storage/        (در صورت APP_DEBUG روی هاست، خطاها اینجا نوشته می‌شود)
```

## انتقال نهایی به هاست (در مرحله آخر انجام می‌شود)
`public/webhook.php` را در `public_html` هاست می‌گذاریم، `.env` را روی هاست تنظیم می‌کنیم و `php bin/set_webhook.php`
(یا یک آدرس موقت) وب‌هوک را ثبت می‌کند. تا آن موقع چیزی لازم نیست.


## نکات انتقال از پروژه پایتون
- فایل‌های `data/temperament_questions.json` و `data/temperaments.json` از پرسش‌نامه واقعی نسخه پایتون تولید شده‌اند.
- `data/foods.json` شامل داده‌های خوراکی نسخه پایتون است؛ برای ورود به MySQL از اسکریپت واردسازی استفاده کنید.
- فایل `.env` شخصی خودتان را با فایل‌های بسته جایگزین نکنید؛ فقط `.env.example` یک الگوی بدون توکن واقعی است.
- ابتدا فقط ربات تستی PHP را اجرا کنید. ربات اصلی پایتون و دیتابیس فعلی آن تا پایان آزمون دست‌نخورده بمانند.
